# Glow Person 案件デスク

実施中の就活支援案件を探し、学生向けの紹介文を編集・コピーしてLINEなどへ共有するためのサイトです。公開リポジトリのため、掲載データは誰でも閲覧できます。

停止案件と過去の参考タブは掲載しません。紹介文は条件と申込先を確認してから送信してください。LINEへの送信は利用者が明示的に操作します。

Google Sheetsからの同期はPerplexity Computerで1時間ごとに実行し、検証済みの公開用データだけをこのリポジトリへ反映します。Googleの認証情報、元データ全体、非公開リポジトリの履歴は含みません。反映には処理・配信の遅延が生じる場合があります。
